# light-smart-crm-release

客户全生命周期CRM 更新发布库（仅发布清单与安装包，不含源码）

本仓库**只存放软件更新物料**：

- `release-manifest.json` —— 更新清单（版本号、更新方式、安装包下载地址与 SHA-256 校验值）
- GitHub Releases —— 安装包 / 便携版 / APK 附件

「客户全生命周期CRM」桌面端自动更新在 Gitee 主渠道不可用时，会把本仓库作为 GitHub 灾备更新源读取此清单。

- 主发布渠道：`gitee.com/kezhong195/light-smart-crm-release`
- 源码私有备份库（不对公开访问）：`github.com/keyinyibeiwu/light-smart-crm`
